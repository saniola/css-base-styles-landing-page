# CSS Base Styles Landing Page

A multi-section landing page for a design/development studio with base CSS styling (typography, colors, spacing), with a portfolio subpage.

## Features

- Hero, services, portfolio, team, and customers sections
- Portfolio subpage (`portfolio.html`) with project filtering markup

## Technology

- Semantic HTML
- CSS (reset, typography, color variables)

## Project structure

```
index.html        Main landing page
portfolio.html     Portfolio subpage
css/
  normalize.css    CSS reset
  styles.css       Site styles
images/            Site images
```

## Running

Open `index.html` directly in a browser, or serve the directory with any static file server, e.g.:

```
npx serve .
```
